Time and Space Complexity

Time Complexity is a way to measure how the running time of an algorithm grows when the input size increases. It helps us understand how efficient our code is. For example, if we search for a number in a list, a small list may take less time, while a large list may take more time. We use Big O notation, such as \(O(1)\), \(O(n)\), and \(O(n^2)\), to describe time complexity.

Space Complexity is a way to measure how much memory an algorithm needs when the input size increases. It helps us understand how efficiently our code uses memory. For example, if we create a new list to store input numbers, the memory required may increase as the number of elements increases. We use Big O notation, such as \\(O(1)\\), \\(O(n)\\), and \\(O(n^2)\\), to describe space complexity.
